## Live-game bug fixes found by the campaign (spec-file fixes, separate)

Three genuine live-game bugs surfaced during the fixture work and were fixed
in isolated changes (they are **not** battery artifacts):

| Lane | Root cause | Fix |
|------|-----------|-----|
| **hunter/BM Trinket** | Lua forward-declaration shadowing: `beast_mastery_sylvanas.lua:78`'s `local is_item_ready` was shadowed by `:458`'s `local function is_item_ready(...)`, so `safe_any` received nil and `trinket_1_ready` was always false — **in live game too** | forward declaration reordered (in `62eb5480`) |
| **druid/bear + cat cache-hit nil-guard bypass** | `bear_sylvanas.lua:365` / `cat_sylvanas.lua:698` returned the **raw state table** on frame-cache hits, bypassing `spec_kit.safe_state` defaults (nil fields leaked as nil) | wrapped in `safe_state(state, SCHEMA)` mirroring `arms_sylvanas.lua:379` (commit `6abb9039`) |
| **warlock leveling cache-hit bypass** | `leveling_sylvanas.lua:327` returned raw `leveling_state` on its cache hit — caught by the new `run_cache_hit_audit_tests.lua` static audit's **first run** | wrapped in `safe_state(leveling_state)` (`168cc21d`) |

The cache-hit family is now mechanically enforced by the static audit
(16/16 cache-bearing files clean; injection-proofed; Lua 5.1 + 5.4
dual-interpreter self-test) plus the semantic guard
`test_cache_hit_nil_guard_regression.lua`.

## Reconciliation of earlier triage predictions

- `never_strategy_triage_non_dps_2026-08-07.md:708` predicted that if the
  ranked (B) #1-20 fixtures landed, "(c) ≈ 62 → ~30; total never-firing ≈
  100 → **~68**, dominated by genuinely situational (b) lanes + snapshot/state
  lanes that live code (not the battery) can't express."
- **Actual result: 13**, not ~68. The gap is the campaign's finding: the
  "genuinely situational (b)" bucket proved largely modelable. PvP pressure,
  snare/CC, race, threat, ally, and enemy-caster states were all expressible
  as battery scenarios + stub surface (batches 3–5), and the 
  snapshot/state lanes shrank to exactly **3** module-local (c) pins
  (RakeSnapshot, RipSnapshot, FireNovaReplacement) plus the correctly-silent
  OOC set. The non-DPS doc's own per-lane tables remain accurate — it was the
  *aggregate projection* that under-predicted the fixture ROI.
- The WotLK-era prediction (`never_strategy_triage_wotlk_2026-08-09.md`,
  "mirror the TBC campaign") is **superseded by outcome**: WotLK is at 0, not
  100-style; see the WotLK triage campaign (2026-08-09) and its regression
  pin `test_wotlk_battery_regression.lua`.
