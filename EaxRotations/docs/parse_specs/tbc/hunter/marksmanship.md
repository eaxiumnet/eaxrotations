## Pinned priority (wowsims precast-only baseline, default behavior)

Dispatch order (first match wins; GCD strategies):

1. `InCombatAimedShot` — Aimed Shot opener, combat_time <= 0.5s, Serpent Sting
   not active, swing-window gated (`can_cast_before_auto(AIMED_SHOT_CAST_MS)`).
2. `SerpentSting` — DoT refresh (refresh window 1.5s; wowsims/tbc tryUsePrioGCD
   applies the sting before the shots).
3. `MultiShot` — AoE only (`aoe_threshold` default 3), swing-window gated
   (MULTI_SHOT_CAST_MS 500).
4. `ArcaneShot` — filler, mana floor 20%.
5. `SteadyShot` — filler, shot-timer-delay gated (hunter_shot_timer_buffer
   default 150ms).

Above the GCD chain sit the non-rotation lanes (potions, Healthstone,
MendPet, Deterrence, pet state, aspects, FreezingTrap, Hunter's Mark,
RapidFire, TrueshotAura, BestialWrath, Readiness, prepull Aimed Shot,
pet/utility DSL lanes, leveling lanes, AdaptiveRotation) — see the strategy
table in the spec file for the full order. APL conformance only enforces the
relative order of the four pinned names.

## Divergence: guide Aimed Shot weave vs wowsims precast-only

wowsims/tbc pins Aimed Shot as a **precast-only** ability: the 0.5s combat
opener lane is the only in-combat cast. The classic hunter guides (3.0s
auto-shot rhythm) weave Aimed Shot **throughout** combat: cast it between
auto-shots whenever the full 2.5s cast fits before the next auto-shot fires
(swing-window gate), replacing the Steady Shot filler.

**Flipped by the `mm_aimed_weave` setting** (Marksmanship tab > Shot Weaving,
checkbox, **default false**):

- OFF (default): byte-equivalent to the pinned wowsims behavior — the
  `AimedShotWeave` matcher's first gate is the setting, so the lane is inert
  and the priority list is unchanged.
- ON: the `AimedShotWeave` lane (inserted after `AimedShotPrepull`, above
  KillCommand/SerpentSting) fires in combat when combat_time > 0.5s, Aimed
  Shot is ready (6s CD), mana >= 20%, and the swing window permits the 2.5s
  cast (`can_cast_before_auto(2500)` — the same era-correct gate the
  vanilla-era 3.0s weave uses). The <= 0.5s opener stays owned by
  `InCombatAimedShot`.

Battery: the lane is battery-observable via the `mm_aimed_weave` scenario in
`behavioral_audit.lua` (setting flipped + combat_time 5), so the TBC never=16
contract does not grow. Strategy-name divergence (TBC-only name) is allowlisted
in `tests/era_pair_seed.lua`; docs/scorecard.md strategy counts regenerated by
`lua tools/spec_scorecard.lua`.
