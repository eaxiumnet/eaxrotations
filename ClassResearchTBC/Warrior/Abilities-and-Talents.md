# Warrior Abilities and Talents

Sources: `../Sources.md`, `../LocalReferences.md`, Icy Veins Warrior spec guides, Wowhead Warrior ability database, Wowhead Warrior talent calculator, Flux Warrior research, Sonah Warrior modules, SlyRotate Warrior module.

## Class Kit

- Stances: Battle, Defensive, Berserker. Many abilities are stance-locked.
- Rage attacks: Bloodthirst, Mortal Strike, Shield Slam, Revenge, Whirlwind, Execute, Slam, Sunder Armor, Devastate if present in target TBC data, Heroic Strike/Cleave on-next-swing.
- Shouts: Battle Shout, Commanding Shout, Demoralizing Shout.
- Mobility/control: Charge, Intercept, Intervene if TBC, Hamstring, Piercing Howl, Intimidating Shout, Pummel, Shield Bash, Disarm.
- Defensives: Shield Block, Shield Wall, Last Stand, Retaliation, Recklessness.
- TBC additions/changes: Rampage, Victory Rush where supported by TBC Classic data, Spell Reflection if supported by target version, improved tanking tools.
- Do not add Wrath+ mechanics: Titan's Grip, Shockwave, Bladestorm, Sword and Board, Heroic Throw.

## Talent Trees

- Arms: Mortal Strike, Improved Slam, Sweeping Strikes, Blood Frenzy support debuff, tactical stance play.
- Fury: Bloodthirst, Flurry, Rampage, Death Wish, dual-wield sustained DPS.
- Protection: Shield Slam, Devastate/Sunder rules depending on target TBC data, Last Stand, Shield Block/Revenge threat loop.

## Rotation-Impacting Abilities

- Arms: maintain Sunder if assigned, Mortal Strike, Whirlwind, Slam immediately after swing, Execute as filler below 20%, Sweeping Strikes for cleave.
- Fury: Bloodthirst and Whirlwind on cooldown, Rampage maintenance, Heroic Strike rage dump, Execute filler below 20% without starving BT/WW.
- Protection: Shield Slam, Revenge, Sunder/Devastate, Shield Block, Heroic Strike rage dump, Demo Shout/Thunder Clap utility where assigned.
- Multi-target: Whirlwind, Cleave, Sweeping Strikes, Thunder Clap, tab-Sunder/Devastate for tank threat.
