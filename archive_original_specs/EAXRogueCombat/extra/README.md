# EAX Rogue Combat — v2.1.0

Combat Rogue automation for TBC on Project Sylvanas.

## Rotation
- `Sinister Strike` is the primary combo point builder.
- `Slice and Dice` maintained before falling off.
- `Eviscerate` as the primary finisher.
- `Rupture` for sustained bleed uptime.
- `Blade Flurry` for multi-target fights.
- `Adrenaline Rush` for energy burst.
- `Kick` for interrupts.

## New in 2.1.0
- **Combo points fixed:** Same fix as Assassination — `me:get_power(COMBOPOINTS_TBC)` on player.
- **Target range cap:** No longer auto-targets enemies beyond 30 yards.

## Install
1. Extract `EAXRogueCombat` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Rogue Combat` in the menu.
