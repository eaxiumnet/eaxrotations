# EAX Paladin Protection — v2.1.0

Protection Paladin tank automation for TBC on Project Sylvanas.

## Rotation
- `Avenger's Shield` as a ranged opener and interrupt.
- `Judgement` on cooldown to maintain Judgement of Wisdom/Light.
- `Holy Shield` maintained for block uptime.
- `Consecration` for sustained AoE threat.
- `Holy Wrath` for AoE undead/demon stun.
- `Righteous Fury` maintained for threat generation.

## Install
1. Extract `EAXPaladinProtection` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Paladin Protection` in the menu.
