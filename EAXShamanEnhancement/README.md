# EAX Shaman Enhancement — v2.1.0

Enhancement Shaman DPS automation for TBC on Project Sylvanas.

## Rotation
- `Stormstrike` on cooldown as the primary physical hit.
- `Lava Lash` on cooldown.
- `Earth Shock` / `Flame Shock` for spell damage weaving.
- `Feral Spirit` on cooldown for burst.
- `Shamanistic Rage` for mana recovery and survivability.
- Weapon imbues: `Windfury Weapon` and `Flametongue Weapon` maintained.
- Totem twisting: `Windfury Totem` + `Grace of Air Totem`.
- `Chain Lightning` and `Lightning Bolt` for burst weaving.
- `Water Shield` maintained on self.

## New in 2.1.0
- **Prepull totems:** Enabled by default.
- **Target range cap:** No longer auto-targets enemies beyond 30 yards.

## Install
1. Extract `EAXShamanEnhancement` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Shaman Enhancement` in the menu.
