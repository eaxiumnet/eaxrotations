# EAX TBC Classic Rotations

TBC Classic WoW rotation plugins for Project Sylvanas bot - All 27 specs.

## Features

- **Full Class Coverage** - All 27 specs across 9 classes
- **Advanced Rotation Logic** - Priority-based spell casting
- **Interrupt Management** - Smart interrupt system with priority targets
- **Defensive Cooldowns** - Layered HP-threshold defensive system
- **Encounter-Specific** - Boss-specific behaviors (hold cooldowns, AoE safety)
- **Leveling Support** - 1-70 leveling with wand/melee fallback
- **Out-of-Combat** - Auto drink/eat, party resurrection, group buffs
- **Visual Overlays** - ESP text and HUD display

## Installation

1. Download the plugin folders you need
2. Place them in your Sylvanas scripts folder
3. Enable the plugins in the Sylvanas menu

## Shared Modules

Each plugin includes these shared modules:
- `interrupt_manager.lua` - Priority-based interrupt system
- `defensive_manager.lua` - HP-threshold defensive cooldowns
- `leveling_manager.lua` - 1-70 leveling support
- `encounter_manager.lua` - Boss-specific behaviors
- `ooc_manager.lua` - Out-of-combat utilities
- `esp_renderer.lua` - Visual overlays
- `racial_manager.lua` - Racial ability system
- `ttd_tracker.lua` - Time-to-death estimation
