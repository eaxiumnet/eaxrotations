# EAX Mage Frost — v2.1.0

Frost Mage rotation automation for TBC on Project Sylvanas.

## Rotation
- `Frostbolt` is the primary filler cast.
- `Ice Lance` fires during Fingers of Frost / Brain Freeze procs.
- `Icy Veins` on cooldown for burst.
- `Frost Nova` for AoE control and kiting.
- `Cone of Cold` as AoE damage and slow.
- `Ice Block` for emergency immunity.

## New in 2.1.0
- **Ice Barrier:** Auto-casts as a damage shield when below 80% HP.
- **Cone of Cold:** Added with toggle (default on).

## Menu Options
- Use Frostbolt, Ice Lance, Icy Veins, Frost Nova
- Use Ice Barrier, Cone of Cold, Ice Block

## Install
1. Extract `EAXMageFrost` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Mage Frost` in the menu.
