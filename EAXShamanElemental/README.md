# EAX Shaman Elemental — v2.1.0

Elemental Shaman DPS automation for TBC on Project Sylvanas.

## Rotation
- `Flame Shock` maintained as the primary DoT.
- `Lightning Bolt` as the primary filler cast.
- `Chain Lightning` for multi-target AoE.
- `Earth Shock` for spell interrupt and high-damage burst.
- `Frost Shock` for defensive slowing of melee attackers.
- `Elemental Mastery` and `Nature's Swiftness` for burst.
- `Totem of Wrath` and `Mana Spring Totem` maintained.
- `Water Shield` maintained on self.

## TBC Cleanup (this version)
- Removed Lava Burst — not available in TBC (Wrath ability).
- Removed Thunderstorm — not available in TBC (Wrath ability).
- Removed Lava Flood — not a real TBC spell.
- Removed Wind Shear — not available in TBC (use Earth Shock for interrupt).

## New in 2.1.0
- **Earth Shock:** Auto-used as a spell interrupt when target is casting/channelling.
- **Frost Shock:** Auto-used to slow moving melee attackers chasing you.
- **Prepull totems:** Enabled by default.

## Menu Options
- Use Flame Shock, Chain Lightning, Lightning Bolt
- Use Earth Shock (interrupt), Frost Shock (slow)
- Totem configuration, prepull totems

## Install
1. Extract `EAXShamanElemental` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Shaman Elemental` in the menu.
