# EAX Shaman Restoration — v2.1.0

Restoration Shaman healing automation for TBC on Project Sylvanas.

## Rotation
- `Chain Heal` for multi-target bounce healing.
- `Healing Wave` for large direct heals.
- `Lesser Healing Wave` for fast emergency heals.
- `Earth Shield` maintained on tank.
- `Mana Tide Totem` on cooldown when mana is low.
- `Healing Stream Totem` for passive group HoT.
- `Grounding Totem` to absorb spells.
- `Nature's Swiftness` + `Healing Wave` for emergency instant heal.
- `Bloodlust/Heroism` on pull (enabled by default).
- `Purge` on enemies with active buffs (enabled by default).
- `Cure Poison` / `Cure Disease` for dispel.

## New in 2.1.0
- **Bloodlust on pull:** Enabled by default.
- **Wrath of Air Totem:** Enabled by default.
- **Purge:** Enabled by default.

## Install
1. Extract `EAXShamanRestoration` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Shaman Restoration` in the menu.
