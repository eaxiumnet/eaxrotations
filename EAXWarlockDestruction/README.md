# EAX Warlock Destruction — v2.1.0

Destruction Warlock DPS automation for TBC on Project Sylvanas.

## Rotation
- Maintains a TBC curse at all times with `Auto` defaulting to `Curse of Elements` and swapping to `Curse of Doom` for long-lived targets.
- Keeps `Fel Armor` active so combat `Life Tap` is only used with the safer TBC sustain setup.
- Maintains `Immolate` and spends `Conflagrate` on cooldown when the debuff is active.
- Uses `Shadowburn` in execute range when a shard is available.
- Spends extra shards on `Soul Fire` above execute range.
- Uses `Incinerate` as the primary filler with `Shadow Bolt` as the fallback filler.
- Uses `Seed of Corruption` on 3+ target packs and `Shadowfury` for clustered control or interrupts.

## Menu Options
- Filler profile: Auto / Incinerate / Shadow Bolt
- Curse mode: Auto / Elements / Agony / Doom / Recklessness / Tongues / Weakness
- Toggles for Fel Armor, Immolate, Conflagrate, Shadowburn, Soul Fire, Seed of Corruption, Shadowfury, Shadow Bolt, Incinerate, and Life Tap

## Install
1. Extract `EAXWarlockDestruction` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Warlock Destruction` in the menu.
