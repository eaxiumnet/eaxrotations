# EAX Priest Shadow — v2.1.0

Shadow Priest DPS automation for TBC on Project Sylvanas.

## Rotation
- Maintains `Vampiric Touch`, `Shadow Word: Pain`, and `Devouring Plague` uptime.
- `Mind Blast` on cooldown when DoTs are active.
- `Mind Flay` as primary filler channel.
- `Shadow Word: Death` in execute range.
- `Shadowfiend` on cooldown for mana regen.
- Maintains `Shadowform` and `Vampiric Embrace` at all times.

## New in 2.1.0
- **Inner Fire:** Auto-maintained as a self-buff.
- **Fade:** Auto-triggers at <50% HP to drop aggro.
- **Psychic Scream:** Auto-triggers at <40% HP for defensive AoE fear.

## Menu Options
- DoT refresh window, Mind Blast burst window
- Use Shadowfiend, Psychic Scream, Fade
- HP thresholds for defensive abilities

## Install
1. Extract `EAXPriestShadow` into your Sylvanas `scripts` folder.
2. Reload or restart.
3. Enable `EAX Priest Shadow` in the menu.
