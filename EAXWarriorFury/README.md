# EAX Fury

Minimal Fury Warrior rotation for TBC.

## What It Is

EAX Fury is a lightweight Project Sylvanas plugin for Fury Warriors. It handles the core rotation, common utility buttons, and a small menu without extra setup.

## Install

1. Put the `EAXFury` folder inside your Sylvanas `scripts` folder.
2. Reload Sylvanas or restart the client.
3. Open the menu and enable `EAX Fury`.

## Use

- Works only on Warriors.
- Default settings are meant to be usable immediately.
- Optional controls cover burst, utility, consumables, and defensive behavior.
